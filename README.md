## AI philosophy
Quotes from Programming education in the AI era. Nature Reviews Psychology, 1-3, (2026). (https://www.nature.com/articles/s44159-026-00612-8)

*Under some circumstances, it might be preferable for  students to produce their own programming solution  before they see what is offered by generative AI; in other words,  programming for the sake of learning.*

*…producing a working programming script no longer  demonstrates competence, which poses a challenge to  assessment efforts.*

**Why should we still learn coding?**
1. To decide how to delegate work to AI.
2. To evaluate the complexity of tasks.
3. **To review AI.**
4. **To be critic with AI outcomes.**

**Good practices with AI**
1. **Be transparent.** Let your collaborators know which tasks were done by AI.
2. **Keep it manageable.** Don't delegate more to AI than you're able to review yourself.
3. **It's OK to skip AI.** Sometimes you might just want to code for fun.
